Tools that generate a navigable scene or world from text, images or video. Exportable: the tool hands you a file. Streamed only: the tool shows you a world and gives you no file. Object-level generators are listed by name and not covered.

Marble

World Labs		 Gaussian splat (SPZ, PLY), 360 panorama PNG, collider mesh GLB, high-quality mesh GLB (Pro), video render $0, $20, $35, $95 per month; API $1.00 per 1,250 credits, one world 1,500 credits Terms: any paid account owns output. Pricing page: commercial rights listed under Pro only. Conflict recorded. No. Hosted web app and API. 2026-09-08
Quotes, tiers and sources

Inputs

  • text: Up to 2,000 characters. Tier: Free and above
  • single image: Recommended resolution: 1024 on the long side. Recommended aspect ratio: 16:9, 9:16, or anything in between. Max file size: 20 MB. Supported formats: png (recommended), jpg, webp. Tier: Free and above
  • multiple images (Direction control mode or Auto Layout mode): Direction control: up to 4 images. Auto Layout: up to 8 images, and all uploaded images need to share the same aspect ratio and resolution, and should be images from the same space. Tier: Pricing page lists Multi-image input under Free. Billing docs list generation from multiple images under Standard. See the report.
  • panorama: Full 360 degree equirectangular projection, in 2:1 aspect ratio. Recommended resolution: 2560 pixels wide. One panorama per world; a panorama cannot be combined with other images or a video. Tier: Free and above
  • video: Max file size: 100 MB. Max duration: 30 seconds. Supported formats: mp4, mov, webm. Tier: Standard and above (pricing page: Video input)
  • other (3D structure upload (Chisel import)): Max file size: 100 MB. Supported formats: glb, fbx. Tier: Pricing page lists Chisel mode under Free. Billing docs list 3D layout input under Standard.

Outputs

  • Gaussian splat, SPZ: About 2M splats; low-res option about 500k splats. Marble native format optimised for file size. Exports default to the OpenGL coordinate system since 11 December 2025, with an OpenCV option. Tier: Standard and above
  • Gaussian splat, PLY: About 2M splats; low-res option about 500k splats. Uncompressed, broader software compatibility. Tier: Standard and above. API: PLY splat exports are free
  • 360 panorama, PNG: Equirectangular png of 2560 x 1280 pixels. Tier: Standard and above
  • Collider mesh, GLB: Coarse mesh optimised for simple physics calculations, 100-200k triangles, typically 3-4 MB. Tier: Standard and above
  • High-quality mesh, GLB: One glb around 600k triangles with texture information; another glb around 1M triangles with vertex colors. Takes up to an hour to generate. Rate limited to 4 generation requests per hour per user. Typically 100-200 MB. Tier: Pro and above. API: 3,500 credits ($2.80) per world
  • Video render: Record mode in Studio with export settings for quality, resolution, aspect ratio, frame rate and codec (release notes, 11 December 2025). Tier: Not stated on the pricing page. Pro adds Enhance rendered video outputs
